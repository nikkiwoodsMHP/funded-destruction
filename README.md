# Funded Destruction — Unified Preview

Cloudflare Worker preview of the Funded Destruction investigative platform, including Follow the Money, environmental case research, classroom resources, and a planned Evidence Desk.

- Project: `holy-resonance-a508`
- Deployment branch: `main`
- Wrangler: `npx wrangler deploy`
- This is a **noindex preview**, not the production website.
- Sensitive submissions, editor access, and financial database writes are disabled until the D1 database, authentication, privacy protection, and anti-spam infrastructure have been configured and tested.
- The existing public FundedDestruction.com website should not be switched to this preview until testing is complete.

This repo was seeded via the connected GitHub integration. No secrets are stored in the repository.
